# skate3-play

Project site for a native static recompilation of **Skate 3** running on Apple Silicon macOS.

Live at **https://uhrichsam4.github.io/skate3-play/**

The site is a static landing page (no build step): `index.html` + `styles.css` + screenshots in `assets/`.

It hosts **no game code, binaries, or assets**. Game files are not distributed here.

Online-play netcode lives at [uhrichsam4/skate3-online](https://github.com/uhrichsam4/skate3-online).
